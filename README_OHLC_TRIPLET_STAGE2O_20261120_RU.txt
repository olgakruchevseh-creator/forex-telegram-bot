ПОСЛЕ GitHub Actions И Railway DEPLOY
Отправить Telegram-боту только:
  /ohlc_triplet EUR/USD

Результат команды:
- для трёх уже сохранённых проверок H1 отображает O/H/L/C из SQLite и RAM;
- восстановленные по округлённым разницам Twelve Data значения помечает «≈»;
- для НОВЫХ ручных проверок сохраняется полный OHLC ответа Twelve Data;
- показывает максимальное отклонение каждой версии от позднего ответа в пипсах;
- отдельно показывает H1 за последние 72 часа: первое сохранение до/после
  пятиминутного порога, позднюю ретроспективную запись и соответствие кешу;
- учитывает уже существующий пассивный журнал изменений, если он доступен.

ЗАПРЕТЫ И ГРАНИЦЫ
- Новых Twelve Data API запросов нет. Команды с «ПОДТВЕРЖДАЮ» не нужны.
- SQLite, кеш, торговая логика, Master, Killer, ATR, H1-close не меняются.
- Результаты прошлых API-сверок восстанавливаются по округлённым
  quote-tick-разницам. Это числовая оценка, НЕ точный исходный JSON API.
- Точные значения могут быть сохранены только в будущих ручных проверках.
- Совпадение с кешем сейчас НЕ подтверждает отсутствие прежних пересмотров.
- Новый прямой ответ Twelve Data не доказывает, что цена была доступна
  боту во время исторического сигнала.
- Временная основа D1/W1 этим этапом НЕ исправляется.
- Историческая дозагрузка НЕ запускается.
