# Forex · Компактный сессионный брифинг для обновлённого ZIP (03.11.2026)

## Основа и область изменений

Основа — **именно** пользовательский `forex-telegram-bot-main (2).zip`.
Текущие `killer_engine.py`, `killer_audit.py`, `killer_trap_guard.py`,
`decision_journal.py`, `daily_calibration_report.py` из этой версии **не изменены**.
С новым ZIP прошлые архивы устанавливать повторно **не нужно**.

## Изменения

1. Публикация брифинга начинается **только после сборки** сводки и карточек.
2. Лидер и приоритет сессии теперь сразу после заголовка общего обзора, а не в финале отдельным сообщением.
3. Одна пара — одна карточка: доступное изображение отправляется вместе с компактной подписью и ключевыми фактами; при отсутствии картинки отправляется компактный текстовый блок.
4. Telegram ограничивает подпись к изображению 1024 UTF-16 единицами. Служебный модуль `briefing_delivery.py` помещает в неё ключевую информацию и ссылку-команду `/briefing_full` для длинного текста.
5. `/briefing` — компактный брифинг, `/briefing_full` — полный текстовый отчёт по запросу.
6. Убрано лишнее предварительное «Собираю брифинг…» по команде `/briefing`.
7. Между сообщениями брифинга — пауза `BRIEFING_SEND_PAUSE_SEC = 0.6` секунды (диапазон 0–2 секунды); отправки двух брифингов в одном чате защищены от взаимного перемешивания.

## Не изменено

Скорость получения котировок и проверки сигналов; закрытие H1; M15/M5; Master; Killer; риски, пороги и блокировки, телеграм-уведомления об отдельных сделках. Пауза между элементами брифинга не влияет на торговые сигналы.

## Установка

1. Распаковать ZIP. Скопировать содержимое папки `forex-telegram-bot-main/` в **корень текущего Forex-репозитория GitHub** с заменой совпадающих имён. Не удалять остальные файлы.
2. После деплоя Railway запросить `/briefing` в Telegram, проверить сначала обзор с лидером, затем картинки пар с текстом прямо под ними.
3. При необходимости запросить `/briefing_full` для полной подробной текстовой версии. Она может состоять из нескольких сообщений — это ограничение Telegram.
4. При желании изменить `BRIEFING_SEND_PAUSE_SEC` в `config.py`, например 0 (без паузы), 0.6 (по умолчанию), 1.0 (более медленная отправка). Пауза влияет только на сессионный брифинг, а не на сканирование рынка.
