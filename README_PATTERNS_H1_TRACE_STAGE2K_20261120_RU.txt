не меняют торговлю и не заменяют свечи. Для /patterns_formation нужен
уже накопленный в RAM-кеше TF; если его нет, дождитесь планового сканирования.

а не доказательство корректной календарной привязки D1/W1 от Twelve Data.

РУЧНАЯ ПРОВЕРКА ПОСТАВЩИКА: НЕ ЗАПУСКАТЬ БЕЗ РАЗРЕШЕНИЯ НА КРЕДИТЫ API.
ПРИМЕР СНАЧАЛА ТОЛЬКО ПЛАНА (0 запросов и 0 записей):

python ohlc_conflict_vendor_manual.py --pair EUR/USD --timestamps 2026-11-16T13:00:00Z

КОГДА ЯВНО РЕШЕНО ПОТРАТИТЬ КРЕДИТЫ и Railway STATE_DIR содержит архив,
с теми же параметрами добавить ДВА ФЛАГА:

--execute --approve-api-requests

Ограничено 1–3 H1-метками за запуск, максимум 3 запроса к Twelve Data.
Отчёт сохраняется в STATE_DIR/ohlc_vendor_conflicts_manual_observe.json;
SQLite не меняется. /ohlc_conflicts покажет сопоставимый статус рядом с часом,
а также станет видно, к какой из ДВУХ версий ближе НЫНЕШНИЙ ответ API.
Остаётся возможность третьей версии: она не исправляется автоматически.

РУЧНОЙ ПИЛОТ ДОЗАГРУЗКИ: ПО УМОЛЧАНИЮ ТОЛЬКО ПЛАН (0 API/0 SQLite).
Пример первых трёх дней из рассчитанного ранее периода:

python h1_backfill_pilot.py --start-date 2026-11-02 --end-date 2026-11-04

Только после явного разрешения затрат API и проверки тарифа:
к той же команде добавить --execute --approve-api-requests

Ограничение: 1–7 ЗАВЕРШЁННЫХ календарных дней на запуск, все 7 валютных пар,
по одному запросу на пару при нормальном ответе. Начало и конец — UTC.
Сначала загрузка всех ответов, затем проверка H1-времени, OHLC и ВСЕХ
основных торговых H1 в окне (иначе полный откат), затем
одна транзакция SQLite для всей корзины. Если один ответ плохой — НИЧЕГО
не записывается. Существующие исходные свечи НЕ перезаписываются;
конфликтующие повторные цены помещаются в revisions с QUARANTINED.
Операция отражается в ingest_runs. Исторические свечи сохраняют дату
их ПЕРВОГО появления в журнале при дозагрузке, не выдают себя за live-сигнал.

Очень важно:
- Ни один из двух ручных инструментов не вызывается из bot.py или scan_job.
- Автоматический backfill в Railway не включён.
- Не вводить ключ API в команды; брать TWELVE_DATA_API_KEY из среды.
- Не выставлять --execute, пока не будет подтверждён лимит плана Twelve Data.
- При затруднении с доступом к терминалу Railway сначала использовать
  только Telegram-команды и сообщить результаты. Не менять основной запуск.
- Для W1 нужна намного более глубокая H1; один пилот не решает задачу.
- Master / Killer / ATR / пороги / рабочий H1-close НЕ менялись.
