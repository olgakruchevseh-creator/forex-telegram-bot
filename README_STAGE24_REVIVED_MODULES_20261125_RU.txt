═══ МАТЕМАТИКА: НАЙДЕНО И ИСПРАВЛЕНО ═══

1. market_adaptation_context — детекторы смены режима врали на шуме
   Проверка: 300 рядов по 120 точек чистого шума N(0,1).
   - Page-Hinkley: копил «сырые» единицы входа (порог 8 без масштаба) →
     ложная тревога в 91 % рядов. Теперь ряд стандартизирован устойчиво
     (медиана + 1,4826·MAD первых 24 точек), δ и порог — в сигмах.
     Стало: ложных 4,7 %, мощность 69 % при сдвиге 1σ.
   - «Адаптивное окно»: брался МАКСИМУМ z по всем точкам разреза и
     сравнивался с 2,6 — порогом для ОДНОГО теста. Максимум ~100 коррелированных
     z превышает его намного чаще → 27 % ложных. Заменено классическим
     CUSUM-тестом точки смены (статистика Колмогорова, критическое 1,358 =
     5 %). Стало: ложных 3,7 %, мощность 99,7 %.
   - Run-length: после сброса история из 1 точки (σ=0) → следующий бар
     «бесконечно» неожиданный → каскад сбросов (1,65 сброса на одну смену).
     Теперь после сброса прогрев 12 наблюдений. Стало: 1,01.
   - Итог «ПЕРЕХОД/СМЕНА РЕЖИМА» (2 из 3 детекторов) на шуме: было 26 %,
     стало 1 %. Формулировка «независимых детектора» исправлена: все три
     смотрят один ряд и независимыми не являются.

2. research_edge_audit — PBO (CSCV) считал половину разбиений
   Разбиение и его дополнение выбрасывались как «дубликаты», но это разные
   проверки (обучение и тест меняются местами). По Bailey–López de Prado
   используются все C(S, S/2): при S=8 — 70, а не 35.
   DSR (дефлированный Шарп): формула проверена, верна.

3. data_quality_guard — каждые выходные считались «дырой в данных»
   48 часов без H1 в субботу–воскресенье давали MISSING_INTERVALS.
   Теперь дыра считается, только если пропущены часы внутри торгового
   времени (календарь definitely_trading_fx). Дубликат метки больше не
   считается одновременно «нарушением порядка» (одна ошибка — один счёт).

4. parameter_stability — падал на нечисловом значении; теперь пропускает.

5. causality_guard — старая статическая проверка искала pandas-операции
   (.shift(-1), rolling(center=True)), которых в проекте нет. Добавлена
   живая проверка перерисовки свингов: swing_repaint_check.

═══ ПОДКЛЮЧЕНИЕ ═══

A. Новый diagnostics_observer.py — раз в каждую новую закрытую H1:
   - data_quality_guard: дыры в торговые часы и «замёрзший» поток по H1/H4/M15/M5;
   - causality_guard: проверка перерисовки ZigZag H1 на реальных данных;
   - market_adaptation_context: смена режима волатильности по log(TR/медиана TR);
   - pair_character: второй независимый оценщик характера пары, сверка
     с pair_character_matrix (расхождение эффективности > 0,15 = тревога).
   Пишет одну строку в лог DIAGNOSTICS_OBSERVE и одну запись в
   STATE_DIR/diagnostics_observe_forex.jsonl (до 5 МБ, затем старая половина
   удаляется). Выключатель: DIAGNOSTICS_OBSERVER_ENABLED = False.

B. robustness_audit (уже работал) теперь добавляет:
   - edge_drift_guard: здоровье преимущества в целом и по каждому модулю;
   - research_edge_audit: вердикт DSR по каждому модулю с поправкой на число
     сравниваемых модулей.
