ЧТО СДЕЛАНО
1) В patterns.py добавлен read-only расчёт senior_figure_state / senior_figure_context:
   - Только W1/D1/H4/H1, подтверждённые закрытые собственные свечи TF.
   - Время жизни: W1 2, D1 3, H4 6, H1 8 последних закрытых свечей.
   - Фигура перестаёт быть активной после закрытия за отменой / достижения
     измеренной цели / окончания срока. Даже первая подтверждающая свеча
     имеет измеренную цель (без зависимости от отсутствующего remaining).
   - H1, подтверждённая РАНЬШЕ H4, не считается откатом от H4.
   - Отношение: aligned / pullback / possible_break / none.
   - Расчётный предел отката — ключевой уровень H4 или его отмена,
     в зависимости от положения ПОСЛЕДНЕЙ ЗАКРЫТОЙ H1.
2) В patterns_mtf.py добавлен replay нескольких предыдущих закрытых
   свечей на W1/D1/H4/H1, потому что production detector видит фигуру
   преимущественно в момент её первого подтверждения. Replay вызывается
   ТОЛЬКО при сборке наблюдательного MTF брифинга, использует существующий
   scan_symbol, не сохраняет OHLC, sent/pending и историю на диск.
   Кэш — максимум 8 пар (или заданный прежним пределом), без массивов свечей.
3) В брифинге новые строки при наличии фактов:
   «Ведущая фигура сессии: H4 ... · D1 совпадает/против»;
   «Контекст: H4 — активная ранее подтверждённая фигура ...»;
   «Вывод: H1 ... — откат внутри H4 ... предел ...» или
   «Вывод: ... возможный слом H4 ... ждать закрытия H4».
   W1 — фон; H4 → D1 → H1 — ПОРЯДОК ИНТРАДЕЙ-ВИТРИНЫ.
   Только 2 строки вывода, M15/M5 — самостоятельные наблюдения.
   Старые строки «Старшая обнаруженная фигура» и «Есть конфликт ...» сохранены.
   Старый список паттернов по-прежнему показывает ТОЛЬКО последнее закрытие,
   историческая H4 выводится отдельным контекстом, а не новым сигналом.
