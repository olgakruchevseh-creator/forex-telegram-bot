1. ZigZag всё ещё перерисовывал историю в тихом рынке (analysis.zigzag)
   Этап 20 убрал перерисовку только при нормальной волатильности. Оставался
   «тихий» запасной порог 0.65: пока основной порог 1.0 давал меньше 4 свингов,
   брался запасной; на свече, где основной набирал 4-й свинг, вся цепочка
   заменялась (было 9 свингов → стало 4). Скользящее окно 250 H1, низкая
   волатильность: 23 перерисовки истории на 2 760 свечах. Стало: 0.
   Тест этапа 20 этого не ловил: он пропускал окна с <4 свингами и проверял
   растущий список, а не скользящее окно, как у провайдера.
   Последствие: в очень тихом окне меньше свингов; направление тогда берётся
   по фазе EMA/ADX (так уже было устроено в bias_of).
   Откат: ZIGZAG_QUIET_FALLBACK_ENABLED = True.

3. «Рядом FVG» (analysis.find_fvgs / analyze_tf, вывод /pair)
   - Закрытые разрывы отсеивались ПОСЛЕ обрезки до 6 последних: если 6 новых
     были закрыты, старый открытый FVG терялся. Теперь фильтр до обрезки.
   - Открытый разрыв, внутри которого стоит цена, раньше пропускался. Теперь
     показывается первым, строкой «Цена внутри … FVG».

4. Фаза «флэт» не зависела от таймфрейма (analysis.phase)
   Порог |EMA21−EMA50| < 0,08 % цены одинаков для W1 и M5. На D1/W1 это
   малая доля одной свечи — «флэт» почти не срабатывал; на M5 это несколько
   свечей — «флэт» ставился на направленном движении. Теперь порог
   0,8 × ATR(14) того же ТФ (на типичном EUR/USD H1 это прежние ~0,08 %).
   Последствие: на D1/W1 «флэт» будет чаще (голос ТФ = 0), на M5 — реже.
   Откат: PHASE_FLAT_ATR_MULT = 0.

ПРОВЕРЕНО И ЛОГИЧНО (без изменений)
 - Сила валют: МНК по графу пар, Σ=0, на звезде из 7 USD-мажоров точное
   S[база]−S[котировка] = доходность пары. Гаусс с частичным выбором ведущего.
 - ADX по Уайлдеру: сглаженные суммы /период = среднее, формула верная.
 - closed_candles: незакрытая последняя свеча отбрасывается по времени UTC.
 - structure_bias / bias_of: зеркально симметричны (бычье = медвежье).
 Замечание без правки: atr() — простое среднее TR (SMA), а не RMA Уайлдера.
 Это не ошибка, но «ATR(14)» в литературе обычно Уайлдера; SMA реагирует быстрее.
