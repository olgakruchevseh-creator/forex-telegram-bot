FOREX PATTERNS 2.0 · ЭТАП 2М · РУЧНАЯ СВЕРКА 25 H1
===================================================

ЭТО НЕ ИЗМЕНЕНИЕ ТОРГОВОГО АЛГОРИТМА.
Никаких изменений Master, Killer, торгового ATR, порогов, правила
«сигналы только по закрытой H1» или отправки сигналов.

ПРОБЛЕМА
По прежним отчётам EUR/USD 25 H1 различаются между сохранённым SQLite
и оперативным RAM-кешем; в 23 случаях разнится только Close. Каждая
из 25 H1 впервые сохранена в первые 6–53 секунды после закрытия.
Это объясняет необходимость сверки, но НЕ доказывает пересмотр Twelve Data,
использование именно этой цены в сигнале или достоверность чужой версии.

ШАГИ ПОСЛЕ УСПЕШНОГО GITHUB ACTIONS И ДЕПЛОЯ RAILWAY
1. Убедитесь, что в Railway заданы TWELVE_DATA_API_KEY и TELEGRAM_CHAT_ID
   (именно ID ЛИЧНОГО диалога с ботом, не группы).
2. /ohlc_conflicts EUR/USD — без API, посмотреть текущие расхождения.
3. /ohlc_verify EUR/USD — БЕЗ API, увидеть предварительный план до 3 H1.
4. Если согласны потратить до трёх API-запросов Twelve Data, отдельно
   отправьте /ohlc_verify EUR/USD ПОДТВЕРЖДАЮ в личный чат Telegram.
   Эта команда является явным ручным разрешением на платные API-запросы.
5. /ohlc_conflicts EUR/USD — прочитать результаты сопоставления.
6. /patterns_formation EUR/USD D1 — контроль D1, пока без подтверждения
   рыночной временной основы.

БЕЗОПАСНОСТЬ
- Никаких API-запросов от /ohlc_verify без слова ПОДТВЕРЖДАЮ.
- Подтверждение разрешено только из личного чата с явным TELEGRAM_CHAT_ID.
- В одной подтвержденной проверке максимум 3 H1, в том числе два самых
  крупных конфликта и один с изменениями иных OHLC (если он имеется).
- Одинаковые уже успешно проверенные H1 не выбираются повторно.
- Ошибки провайдера не перезапрашиваются автоматически в течение 6 часов.
- Результаты нескольких разных запусков объединяются по (пара, TF, UTC).
  Архив SQLite не изменяется; рабочие цены и сигналы не меняются.
- Предварительная проверка источника не доказывает, какая цена была
  доступна на дату реального торгового решения.
- При отсутствии SQLite или RAM-кеша запросы не выполняются.
- Доступность старых H1 и расход API-кредитов зависят от тарифа поставщика.

НЕ ИЗМЕНЯЛИ
- Автоматический H1-поток и действующую задержку 5 минут.
- D1/W1-границы и детекторы Patterns (нет ещё доказательств часовой основы).
- Ручной 7-дневный H1-пилот дозагрузки: без отдельного явного запуска он
  остаётся неактивным. Многолетняя история не загружалась.

ТЕСТИРОВАНИЕ
Проверки имитируют API, не делают настоящих сетевых запросов.
Полный GitHub Actions после установки обязателен: локально может не быть
python-telegram-bot и всех зависимостей бот-модуля.
