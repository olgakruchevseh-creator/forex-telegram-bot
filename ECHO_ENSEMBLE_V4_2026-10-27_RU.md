# Echo Ensemble V4 — Forex — 2026-10-27

Доработан существующий `echo_projection.py` без создания второго Echo-модуля.

Что изменено:
- Top-K аналоги теперь ранжируются не только по нормализованной геометрии H1, но и по корреляции локальной формы доходностей и совместимости рыночного режима.
- Режим учитывает нормализованный тренд, относительную волатильность, эффективность движения и мягкий сессионный признак.
- При достаточной истории приоритет получают аналоги того же режима; при недостатке выборки используется причинный нормализованный пул без выдумывания направления.
- Добавлен настоящий эмпирический Q25–Q75 коридор для каждого горизонта. PNG использует этот коридор вместо синтетической ширины от confidence.
- Медианный путь больше не подгоняется под выбранную сторону. Если weighted-share и медиана спорят, Echo помечается слабее.
- Существующий Next Pivot переиспользуется как bounded read-only подтверждение/конфликт. Он не может перевернуть сторону Echo.
- Добавлен `confidence_score` — качество ансамбля аналогов (не вероятность сделки), плюс similarity/regime/corridor diagnostics.
- Сохранён контракт: только закрытая H1, без нового торгового сигнала и без владения TR1/TR2/TR3.
