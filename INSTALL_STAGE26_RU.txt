FOREX STAGE 26 — КАК ПРАВИЛЬНО УСТАНОВИТЬ (25.11.2026)
======================================================
Это МАЛЕНЬКОЕ ОБНОВЛЕНИЕ существующего forex-telegram-bot-main.
Это НЕ полный исходный проект, не готовый для отдельного запуска на Railway.

ВАЖНО: GitHub не распаковывает загруженный ZIP автоматически.
Нельзя просто загрузить ZIP как один файл и ожидать, что бот обновится.

Правильная установка (GitHub через браузер):
1. На устройстве РАСПАКОВАТЬ этот ZIP.
2. В GitHub открыть СУЩЕСТВУЮЩИЙ репозиторий forex-telegram-bot-main.
3. Открыть корень репозитория (рядом с bot.py, config.py, requirements.txt).
4. Нажать Add file -> Upload files (на мобильном можно включить режим ПК).
5. Выбрать РАСПАКОВАННЫЕ файлы из этого ZIP — НЕ архив как единый файл.
6. Для файлов с существующими именами подтвердить замену и Commit changes.
7. Не удалять остальные файлы проекта, Railway Volume, OHLC, SQLite, JSONL.
8. После коммита проверить GitHub Actions и успешность Railway Deploy.

СОДЕРЖИМОЕ: 12 обновлённых файлов Python + 3 тестовых файла Python
+ оригинальный README + эта инструкция = 17 файлов.
Никаких новых торговых параметров, порогов или сторон сигналов при
перепаковке не изменялось — байты исходных 16 файлов идентичны.
