2. ЧТО ДОБАВЛЕНО В 28F
- Команда /disbalance_calibration [EUR/USD] — ручное исследование Disbalance
  по существующему сохранённому forex_ohlc_history.sqlite.
  Путь: readonly SQLite -> временный CSV экспорт -> исторические снимки по
  ПОЛНОСТЬЮ закрытым H1/H4/D1/M15/M5 -> реальная функция disbalance.analyze_symbol.
  Проверяются качество и гипотетический результат +1 ATR до -0.75 ATR за
  следующие 8 полных H1 без ночного переноса. Одновременное касание цели
  и отмены внутри H1 считается неоднозначным. Есть TRAIN/TEST с отступом.
  НЕ является полным воспроизведением Master/Killer, отправки Telegram,
  рыночного исполнения и спреда; эти события НЕЛЬЗЯ называть сделками.
  Возможные ревизии OHLC задним числом не подтверждают live-видимость данных.
  Если данных мало, отчёт честно сообщает INSUFFICIENT, веса не меняются.
- Команда /w1_finality — чтение локального RAM-кэша W1 без API:
  сравнение формального правила +7 дней и приблизительной пятничной границы
  Forex в 17:00 America/New_York с учётом летнего времени.
  Само пятничное время НЕ доказывает финализацию W1 поставщиком Twelve Data.
  Боевые W1-свечи и их период закрытия НЕ меняются.
- Обе команды доступны только владельцу через существующий _owner_handler;
  запускаются вручную и не создают новых автоматических отправок.
- Общие настройки этапа 28F в config.py:
  STAGE28F_CALIBRATION_DIAGNOSTICS = True
  STAGE28F_W1_FINALITY_DIAGNOSTICS = True
  STAGE28F_CALIBRATION_MAX_ANCHORS = 96
  При необходимости выключить диагностические команды — поставить флаги False.
