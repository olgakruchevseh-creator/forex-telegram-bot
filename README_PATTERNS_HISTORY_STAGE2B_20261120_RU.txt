PATTERNS 2.0 — ИСТОРИЧЕСКОЕ ПОКРЫТИЕ, ЭТАП 2Б
20.11.2026 · маленький технический патч на основе обновлённого Forex ZIP (3)

ГЛАВНОЕ
Текущий рыночный кеш загружает 100 W1, 200 D1 и лишь 250 H1.
Поэтому большинству старых W1/D1 событий не хватает H1-истории для
достоверного replay. Нельзя выдавать созрели=0 за неудачные паттерны.

ФАЙЛЫ
1) patterns_history.py — ЗАМЕНИТЬ в корне Forex-репозитория.
2) test_patterns_history_coverage_stage2b_20261120.py — ДОБАВИТЬ туда же.
3) README_PATTERNS_HISTORY_STAGE2B_20261120_RU.txt — справка, не обязательно загружать.

ИСПРАВЛЕНИЯ
- В отчёте /patterns_history EUR/USD показаны фактический диапазон H1 и
  число H1, дополнительно прочитанных из существующего локального SQLite-журнала.
- История расширяется ТОЛЬКО если файл OHLC-журнала уже существует в STATE_DIR;
  чтение осуществляется в режиме SQLite read-only, максимум 12 000 H1 по одной
  запрошенной валютной паре. Дополнительные запросы к Twelve Data НЕ выполняются.
- При отсутствии журнала отчёт честно использует только обычные доступные H1.
  Для охвата W1/D1 может потребоваться отдельный проверенный архив H1 и
  корректное историческое воспроизведение; патч не подделывает свечи.
- NO_H1 теперь объясняется (нет H1 на дату, недостаточно для ATR, разрыв
  между подтверждением и будущими H1 и т. д.). Для каждого TF есть итоговые
  количества TARGET / INVALID / TIME / AMBIGUOUS / NO_H1 / INCOMPLETE.
- Формирование H1 считается по реально имеющимся закрытиям H1; при
  неполном покрытии — н/д, а не неверное частичное количество.
- Исход НЕ оценивается на далёкой будущей свече через разрыв данных > 4 ч.
  Такая ситуация считается недостатком покрытия, не победой и не поражением.
- В подписях уточнены медианные откаты и время до исхода/горизонта.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Архивные свечи, загруженные задним числом, не доказывают, какие данные бот
  видел в момент первоначального сигнала. Это ретроспективный OHLC-расчёт.
- +1 ATR / -0.75 ATR / 8 H1 — СТАНДАРТ НАБЛЮДЕНИЯ, не реальные TR1/TR2/TR3.
- Историческую статистику пока нельзя автоматически использовать как
  показатель вероятности торгового сигнала.
- Брифинги, сигнальные модули, Forex Killer, H1-решения, пороги, и
  минуты расписания не изменены.
- Анализ по-прежнему запускается только явной командой /patterns_history.

ПОРЯДОК УСТАНОВКИ
1. Скачай этот ZIP и распакуй.
2. В GitHub замени patterns_history.py, добавь новый файл test_patterns_history_coverage_stage2b_20261120.py.
3. Сохрани изменения (Commit changes), дождись зелёного GitHub Actions.
4. Убедись в успешном деплое Railway.
5. В Telegram напиши /patterns_history EUR/USD и пришли результат — особенно
   строки "Покрытие H1" и "Причины недостатка данных" для W1 и D1.
6. Если в Railway нет сохраняемого OHLC-журнала или он короткий, нулевые
   зрелые W1/D1 могут остаться корректным результатом недостатка H1.

ПРОВЕРКИ
33 целевых и смежных теста PASS в изолированном прогоне.
Дополнительно синтетическая проверка 10 000 H1 / 6 TF: ~1.94 с на
локальной среде, без подключения к провайдеру; это НЕ гарантия нагрузки
Railway. Более широкий набор тестов не завершился в установленный лимит;
полный прогон проверить в GitHub Actions.
