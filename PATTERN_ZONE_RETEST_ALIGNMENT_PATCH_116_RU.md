# Patch 116 — Pattern / Zone / Retest alignment

Точечная сверка по 8 референсным скриншотам от 04.10.2026.

## Что уже было в проекте и не дублировалось
- восходящий / нисходящий / симметричный треугольник;
- падающий / восходящий клин, флаг, вымпел, прямоугольник;
- двойная вершина / двойное дно с пробоем линии шеи;
- Head & Shoulders / inverse H&S с расчётной линией шеи;
- BOS и HH/HL/LH/LL-контекст;
- Consolidation Zone с подтверждённым выходом;
- отдельный строгий BOS -> удержание -> отдельный ретест -> реакция (`retest_confirmation.py`).

## Что усилено
`patterns.py`: пробой границы графической фигуры теперь обязан иметь не только закрытие за границей, но и минимальное тело импульсной свечи `0.35 ATR`. Буфер пробоя вынесен в конфиг (`0.05 ATR`). Это отсеивает слабые проколы/микро-закрытия, которые на референсах не соответствуют Strong Breakout.

## Важный принцип
Паттерн, трендовая линия или первое касание зоны сами по себе не создают новый LONG/SHORT. Ретест не был повторно реализован внутри Pattern Scanner: используется существующий строгий `retest_confirmation.py`, чтобы не было двух разных трактовок одного события.

Цепочка проекта после сверки: геометрия/зона -> сильный закрытый пробой -> структура -> существующий lifecycle ретеста -> реакция/удержание -> направление в общей veto/confirmation цепочке.
