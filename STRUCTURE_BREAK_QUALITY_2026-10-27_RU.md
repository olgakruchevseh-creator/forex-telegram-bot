# Настоящий слом структуры — усиление Forex · 27.10.2026

Внедрён общий контракт качества для уже существующих BOS/ретестов. Новый независимый сигнал-модуль не создавался: существующие MSS/CHOCH, Liquidity, FVG/IFVG, Order Block/Breaker и Retest остаются владельцами своей геометрии.

## Что проверяется перед живой публикацией

Пять признаков качества:
1. реакция/отказ от старшего TF;
2. важная зона старшего TF;
3. displacement импульсной свечи;
4. закрытие через структурный уровень;
5. зона интереса после импульса: FVG / origin Order Block / подтверждённый Breaker-Retest.

Отдельно обязательно подтверждается последующий H1 retest/reclaim. Для нового live-setup обязательны displacement + structural close + H1 retest/reclaim, минимум 3 из 5 признаков и наличие зоны интереса/HTF-контекста. Финальное решение остаётся только по закрытой H1; M15/M5 не получили права финального триггера.

## Где включено

- `chain_entries.py` — Chain Entry публикуется только после общего контракта настоящего слома.
- `retest_confirmation.py` — структурный ретест использует тот же контракт, чтобы два модуля не расходились в трактовке BOS.
- `structure_break_quality.py` — единая математика качества.

Старые persisted Forex setups, созданные до патча, не уничтожаются и не получают ретроспективный жёсткий veto: новый hard-gate действует на setups, созданные новой версией логики. Это защищает Railway state при обновлении.

## Что не менялось

- TR1/TR2/TR3 и invalidation;
- H1-close contract;
- существующие MSS/CHOCH/FVG/OB/Breaker движки;
- источники котировок и частота запросов;
- Telegram lifecycle/dedup.

## Проверка

- новые тесты качества: strong break + retest проходит; слабый close-break без displacement блокируется;
- структурный контур после патча: 18/18;
- расширенный Forex-контур MSS/Demand-Supply/Liquidity/Imbalance/OB/Breaker/Structure: 45/45.
- полный pytest в текущей рабочей среде не собирается только из-за отсутствующего внешнего пакета `telegram` при импорте `bot.py`; это не ошибка патча.
