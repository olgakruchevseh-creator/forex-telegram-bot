# Layer 33 — аудит математической зависимости

Статус: **OBSERVE_ONLY**.

Layer 33 выполняет детерминированный leave-one-out (jackknife-style) аудит математического стека Layers 21–32. По очереди исключается каждая производная координата и пересчитывается консервативный агрегат. Цель — обнаружить скрытую ситуацию, когда общий математический вывод чрезмерно зависит от одного показателя.

Это не дублирует Layer 31: там проверяется совместный неблагоприятный стресс. Не дублирует Layer 32: там проверяется устойчивость к малым смешанным возмущениям. Здесь измеряется **single-point dependency** — насколько вывод меняется при полном исключении одной координаты.

Выходы: `dependency_health`, `max_influence_coordinate`, `max_single_influence_pct`, `influence_concentration_pct`, `leave_one_out_scores` и состояние `DISTRIBUTED_SUPPORT / DEPENDENCY_WARNING / SINGLE_POINT_DEPENDENCY`.

Слой не меняет LONG/SHORT, вероятности, пороги, veto, Telegram и входы. Политика закрытой H1 сохранена; M15/M5 остаются только подтверждением.
