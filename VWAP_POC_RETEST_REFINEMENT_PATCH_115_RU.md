# VWAP / POC — точечное усиление ретеста (patch 115)

Non-destructive refinement поверх существующего VWAP/POC lifecycle.

- Первое касание POC/VWAP теперь строго остаётся контекстом и не может сразу стать LONG/SHORT.
- ACCEPTANCE / REJECTION допускается только при повторном взаимодействии (retest) в заданном окне.
- После реакции по-прежнему обязательно существующее структурное подтверждение; отдельный голос/стратегия не создаётся.
- Если провайдер реально дал volume и настоящий VWAP доступен, близость VWAP к POC даёт только небольшой bounded quality bonus (+3), но не направление.
- На графике настоящий VWAP отображается отдельно, только когда он фактически рассчитан из provider volume.
- Для physical FX без volume сохраняется безопасный TPO/price-acceptance POC; синтетический VWAP не создаётся.
