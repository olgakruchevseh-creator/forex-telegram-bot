# FVG / IFVG Lifecycle Patch 104

Точечный non-destructive patch для существующего `imbalance.py`.

## Что изменено
- FVG больше не исчезает автоматически после подтверждённого пробоя закрытой свечой.
- Прокол границы только тенью **не** создаёт IFVG.
- Закрытие за дальней границей переводит FVG в `ПРОБИТ → IFVG` и меняет роль зоны.
- Сам факт IFVG не является самостоятельным LONG/SHORT-сигналом.
- Для IFVG требуется обратный ретест и подтверждение существующим `zone_reaction_confirmation`.
- Сохраняются заполнение зоны и количество тестов.
- Добавлены состояния жизненного цикла: `СОЗДАН`, `ТЕСТИРУЕТСЯ`, `ПРОБИТ → IFVG`, `IFVG → РЕТЕСТ`, `IFVG → ПОДТВЕРЖДЁН`, `IFVG → ОТМЕНЁН`.
- IFVG отменяется только закрытой свечой, нарушающей его новую роль; отменённое состояние сохраняется в state для диагностики.
- Существующие BPR, Silver Bullet, PO3×FVG, Breaker/Mitigation, Structure и KILLER-пороги не менялись.

## Файлы патча
1. `imbalance.py` — обновлённая рабочая логика.
2. `test_ifvg_lifecycle_v104.py` — регрессионные тесты IFVG lifecycle.
3. `FVG_IFVG_LIFECYCLE_PATCH_104_RU.md` — описание патча.
