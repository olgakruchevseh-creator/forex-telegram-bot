# Layer 25 — Evidence Information Value

Статус: OBSERVE_ONLY.

Добавлено математическое измерение информационной ценности доказательств поверх Layers 21–24:
- diminishing-return information mass: повторы одной семьи дают убывающую прибавку;
- нормализованное разнообразие независимых семейств;
- разнообразие таймфреймов с сохранением иерархии W1/D1/H4/H1;
- contradiction index для математически конфликтующего набора;
- итоговый information_value с состояниями INFORMATIVE / MODERATE_INFORMATION / LOW_INFORMATION / CONFLICTED_INFORMATION.

Layer 25 не меняет направление, рабочую вероятность, пороги, veto, Telegram и правила входа. M15/M5 остаются только подтверждением. Политика закрытой H1 сохранена.
