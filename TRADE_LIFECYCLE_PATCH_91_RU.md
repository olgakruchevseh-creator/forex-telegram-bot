# Trade Lifecycle — patch для базы №91

Единый статус решения без новой стратегии и без нового KILLER-семейства.

## Что добавлено
- `trade_lifecycle.py`: статусы `NEW_ENTRY` / `MANAGE` / `WATCH` / `STAND_DOWN`.
- Новости как режим, а не только топор:
  - до события — пауза нового входа, сопровождение можно;
  - сюрприз по сценарию — новый вход не режется только из-за окна «после новости»;
  - сюрприз против — пауза;
  - релиз без сюрприза — наблюдение.
- Сессионный характер: азиатское накопление/баланс не даёт новый вход.
- Поздний путь до TR1/TR3 и съеденный импульс = `MANAGE`, не новый сигнал.
- Корреляция USD: вторая пара с той же ставкой на доллар не становится вторым новым входом.

## Куда встроено
- `master_direction.py` — новый Master-сигнал только при `allow_new_entry`.
- `signal_navigator.py` — significance gate пишет статус и причину.
- `bot.py` — лог отказа содержит статус жизненного цикла.
- Карточка Master показывает строку «Статус решения».

## Что не менялось
- KILLER 88 / 5 семейств.
- Не создан отдельный сканер или семейство доказательств.
- TR1/TR2/TR3 не переводились.
