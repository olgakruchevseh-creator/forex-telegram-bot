# Layer 37 — Pairwise Interaction / Leave-Two-Out Audit

Статус: **OBSERVE_ONLY**.

Layer 37 продолжает Layer 36 и проверяет скрытую зависимость математического вывода сразу от **двух** первичных координат Layers 21–29. Для каждой из 36 пар рассчитывается результат после одновременного исключения двух координат.

## Что измеряется

- baseline математического стека;
- leave-two-out score для каждой пары;
- влияние каждой пары на baseline;
- dominant pair — наиболее влиятельная пара;
- interaction excess — дополнительное совместное влияние сверх более сильного одиночного влияния;
- концентрация влияния и разброс leave-two-out результатов;
- итоговый pairwise health.

Это не статистическая и не причинная модель взаимодействия. Слой является детерминированным стресс-аудитом внутренней геометрии математического стека.

## Безопасность

Layer 37 не меняет ЛОНГ/ШОРТ, вероятность, торговые пороги, veto, Telegram и закрытую H1. M15/M5 остаются только подтверждением. Meta-слои не считаются независимым подтверждением сделки.
