# Личный FX-бот (мультитаймфрейм)

Бот смотрит 7 мажоров сразу на:

- неделя (W1)
- день (D1)
- 4 часа (H4)
- час (H1)
- 15 минут (M15)
- 5 минут (M5)

Сила валют считается по **H1**.
Сигнал `LONG` / `SHORT` уходит только если:

1. минимум 2 из 3 старших ТФ (W1 / D1 / H4) смотрят в одну сторону и нет конфликта
2. минимум 2 из 3 младших ТФ (H1 / M15 / M5) смотрят туда же
3. сила валют это подтверждает

Иначе бот молчит.

Также пишет, когда в рейтинге силы валюта прыгнула минимум на 2 места.

## Запуск

```bash
cd fx-signal-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

В Telegram: `/start`

Команды:
- `/now` — сила валют
- `/pair EUR/USD` — стек всех таймфреймов по паре
- `/status`

Платный Twelve Data: 7 пар на одном ТФ забираются одним batch-запросом.
Полный скан — 6 запросов ≈ 42 кредита. Проверка каждые 5 минут.

## Подкрутить

| Что | Где |
|---|---|
| Мало сигналов | `PAIR_STRENGTH_MIN`, `HTF_MIN_AGREE`, `LTF_MIN_AGREE` |
| Много шума с 5м | поднять `ZIGZAG_PCT["M5"]` |
| Старшие слишком строгие | `HTF_MIN_AGREE = 2` оставить, или ослабить силу |
| Кэш / частота | `ttl_min` у таймфрейма в `TIMEFRAMES` |

Правило сигнала: `decide_signal` в `analysis.py`.

## Railway: постоянное состояние

На Railway диск контейнера временный. После рестарта файлы рядом с кодом пропадают.

Нужно:

1. Подключить постоянный **Volume**.
2. Точка монтирования: `/data`.
3. Переменная: `STATE_DIR=/data`.

Тогда постоянно хранятся три файла:

- `/data/state.json` — чат, брифинг, отправленные сигналы
- `/data/briefing.db` — атомарный замок часового брифинга
- `/data/levels_state.json` — уровни
- `/data/patterns_state.json` — паттерны

Важно: путь `/data` без подключённого Volume **не** является постоянным хранилищем.

Обязательно для одного брифинга на одну H1:

- Volume подключён, точка монтирования `/data`
- переменная `STATE_DIR=/data`
- **одна** реплика worker, не две и не три
- старые дублирующие сервисы того же бота выключены
- не запускать второй Railway-сервис с тем же Telegram-токеном
