# Chain-fix patch для базы №97

Точечные разрывы аудита №97, без новой стратегии и без смены порогов KILLER 88 / 5 семейств.

## Исправлено

1. **Сессионные часы Master/lifecycle** всегда `Europe/Amsterdam`, а не `datetime.now()` хоста.
2. **Session Cycle** считает naive-метки свечей как UTC (как в запросе Twelve Data) и переводит в локальную зону, а не наклеивает Amsterdam поверх UTC.
3. **`weak_reversal`** больше не жёсткий veto в `setup_adjustment` / Master / `signal_context.verdict`. Это штраф или запрет только вместе с враждебным H4.
4. **Обязательные AMD / пробой уровня / PDH-PDL** не выпадают из Master из-за лимита 4: их пары проходят `priority_keys`.
5. **Стабильный event id**: живая цена и баллы качества не меняют отпечаток события.
6. **Очередь кандидатов без времени закрытия** не становится новым входом спустя >1.25 H1.
7. **Ретрай source-outbox** снова шлёт карточку с картинкой, не голым текстом.
8. **TTL H1/M15 = 1 минута**, чтобы закрытый бар не ждал до 3 минут.
9. Удалены мёртвые `signal_context-1.py` и `signal_context.zip`; `.gitignore` их держит снаружи.

## Не менялось

KILLER 88 / 5 семейств, набор сканеров, TR1–TR3, доктрина «карточка источника + Навигатор-сопровождение».
