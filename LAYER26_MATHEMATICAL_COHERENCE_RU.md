# Layer 26 — Mathematical Coherence & Cross-Estimator Agreement

Режим: **OBSERVE_ONLY**.

Layer 26 не добавляет ещё один голос за ЛОНГ/ШОРТ. Он проверяет, согласны ли между собой уже независимые математические оценки Layers 21–25.

Добавлено:
- cross-estimator gap: разрыв между структурно-калибровочным `shadow_probability` Layer 21 и Beta-сглаженной поддержкой Layer 23;
- RMS dispersion: разброс quality / stability / confidence / resilience / information value;
- data readiness: совместная зрелость исторической reliability и достаточности текущей информации;
- итоговый `mathematical_coherence` со статусами `COHERENT / PARTIAL_COHERENCE / INCOHERENT / NO_FACTS`.

Это позволяет отдельно видеть ситуацию, когда общий набор цифр выглядит сильным, но разные математические способы оценки фактически расходятся.

Безопасность сохранена: слой не меняет направление, live probability, пороги, veto, Telegram и правила входа. M15/M5 остаются подтверждением, основные сигналы сохраняют политику закрытой H1.
