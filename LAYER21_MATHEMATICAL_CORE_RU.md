# Layer 21 — Единое математическое ядро (OBSERVE_ONLY)

## Цель
Layer 21 не является новой торговой стратегией. Он переводит результаты существующих экспертных модулей в единую математическую систему координат, не меняя их уникальную логику обнаружения.

## Что считается
- **Quality coordinate** — качество структуры сценария, отдельно от вероятности.
- **Effective evidence families** — эффективное число независимых семейств подтверждений (inverse-Herfindahl / Simpson effective N), поэтому несколько фактов одной семьи не считаются несколькими независимыми голосами.
- **Conflict ratio** — доля направленных фактов против кандидата.
- **Directional entropy** — неопределённость LONG/SHORT доказательств.
- **Reliability** — зрелость и качество исторической калибровки Layer 14.
- **Uncertainty** — отдельная мера неопределённости.
- **Shadow probability** — консервативная параллельная оценка, сжатая к 50% при слабой статистике. Она НЕ заменяет текущую вероятность сигнала.

## Безопасность
- OBSERVE_ONLY.
- Не создаёт LONG/SHORT.
- Не меняет текущую вероятность, quality, veto или пороги.
- Не отправляет Telegram.
- Политика закрытой H1 сохранена; M15/M5 остаются только подтверждением.

## Дальнейшая калибровка
Shadow probability должна оцениваться только по отложенным исходам и point-in-time данным. Для сравнения формул использовать Brier/reliability, walk-forward и purge/embargo там, где окна исходов перекрываются. До накопления достаточной выборки новая математика остаётся диагностической.
