# Forex — адресный аудит 11 отказов GitHub Actions, 07.11.2026

Источник: актуальный `forex-telegram-bot-main.zip` пользователя. Внешние рыночные данные и Railway Volume не менялись.

## Исходное состояние

GitHub Actions с официальным python-telegram-bot успешно установил зависимости и запустил полный набор тестов; первоначально 1033 PASS, 11 FAIL. Основные отказавшие тесты находились в `test_integration_consistency.py` и `test_scanners.py`.

## Исправления

1. **H4 против рабочего сигнала:** в `config.py` включён `SIGNAL_BLOCK_OPPOSITE_H4_ZIGZAG=True`. Это реально усиливает защиту и МОЖЕТ уменьшить количество сигналов. Нейтральный H4 ZigZag (0) сам по себе не считается конфликтом; при ошибке проверки фильтр прекращает выпуск. В `analysis.py` и `bot.py` уже имелась логика ограничения, поэтому сами правила не переписывались.
2. **Общая закрытая H1:** в `bot.py` функция `last_closed_h1_dt()` теперь использует наиболее частое UTC-время последней закрытой свечи всех доступных валютных пар, а не максимальное значение одного лидирующего потока. При равенстве выбирается более раннее время. `closed_bar_utc()` теперь сохраняет часовой пояс входной метки.
3. **Состояние M15/M5:** в `master_direction.py` восстановлена независимая функция `_lower_timeframes_fresh()` для проверки, что завершённые M15 и M5 относятся к последней закрытой H1. Она предназначена для теста/диагностики и не добавляет новый глобальный блокирующий фильтр. Дополнительный торговый запрет намеренно не активирован без статистики его влияния.
4. **Отдельный контекст ZigZag:** в `bot.py` восстановлена функция `is_context_alert()` для различения информационного отката и структурного события. Используется в тесте; основная система допуска торговых сигналов не менялась.
5. **Гармонические модели:** в `patterns.py` для Gartley/Bat исправлено отношение ценового отката A→D относительно XA. Модели-расширения Butterfly/Crab и другие оставлены с прежней X→D-геометрией. Гармонический подтверждающий фильтр всегда требует достаточной разницы силы валют. Это может уменьшить количество гармонических сигналов.
6. **Геометрический антиспам:** `Pattern` получил необязательное поле `geometry_id` без нарушения прежнего конструктора. Для сформированных гармонических моделей ключ события закреплён за точкой D, чтобы повторные обработки той же фигуры не создавали новые сигналы. Новая самостоятельная геометрия может быть уведомлена отдельно.
7. **Старые тесты:** `test_scanners.py` исправлен для текущей наклонной линии шеи H&S и нового расположения треугольников в `chart_patterns()`; сохранена проверка первого закрытого пробоя и запрет wick-only. `test_pattern_geometry_quality_v119.py` приведён к правильному Gartley/Bat откату и содержит негативный тест неправильной D-точки.
8. **Регрессии:** добавлены 6 дополнительных тестов для H1, UTC-offset, H4, свежести M5, силы валют и геометрического антиспама.

## Проверки

- Локально все 1050 тестов pytest завершились успешно. **Ограничение:** Telegram в локальной диагностической среде заменён временной заглушкой импортов для запуска тестов; заглушка НЕ входит в ZIP и НЕ доказывает работоспособность настоящего Telegram API.
- Полноценный запуск с установленным `python-telegram-bot[job-queue]==22.8` нужно выполнить через уже настроенный GitHub Actions. Только зелёный результат GitHub подтверждает прохождение в реальной тестовой среде.
- Проверена компиляция изменённых файлов Python.
- Показатели реальной прибыльности и блокировок нельзя выводить из количества успешных тестов.

## Риски и дальнейшее наблюдение

- Включённый H4-фильтр и строгая сила валют для гармоник могут снизить число уведомлений; необходимо контролировать `Daily Calibration` и причины отказов как минимум несколько рабочих сессий. Не ослаблять H1 gate и не считать контр-трендовые M15 самостоятельным основанием.
- Тест `_lower_timeframes_fresh()` не является доказательством того, что все пути выпуска Master уже сверяют M5; для отдельного включения жёсткой проверки потребуется анализ последствий на истории.
- Перед загрузкой в GitHub сохранить текущую копию. Заменить только файлы этого пакета. Railway Volume, STATE_DIR и токены не трогать.
- Если GitHub Actions покажет отказ, прислать текст `short test summary info` и подробный traceback без токенов.
