# Модуль №9 — Candle Range Theory (CRT)

Аудит 2026-10-07. База: актуальный ZIP пользователя.

## Сохранено
- Только закрытая H1 для основного события.
- Sweep одной границы + close-back внутрь reference range.
- Подтверждение delivery через 50% диапазона.
- H4/M15 используются как фильтр, M15 не становится самостоятельным сигналом.
- Currency Strength, AMD confluence, OHLC guard, state/delivery dedup, chart.

## Усилено
- По умолчанию включена каноническая последовательность reference -> manipulation без пропущенной H1.
- Double sweep обеих границ отбрасывается как неоднозначный CRT.
- Quality теперь учитывает sweep depth относительно самого CRT range, глубину close-back и rejection wick.
- В событие добавлена явная фаза P3_DELIVERY_CONFIRMED и диагностические метрики reclaim/sweep.
- Telegram-карточка показывает фазу и нормализованные характеристики CRT.

## Почему без отдельного нового модуля
CRT остаётся одним источником SESSION_MODEL и не дублирует AMD, Liquidity Sweep, FVG или MSS. Эти данные остаются confluence/filters.

## Не переносилось из внешних реализаций
- ML-фильтр: без собственной статистики проекта создаст ложную точность.
- Жёсткие проценты цены из equity-сканеров: для 7 FX-пар ATR-нормализация проекта корректнее.
- Самостоятельные M15/M5 CRT-сигналы: противоречат политике закрытой H1.
- Вход на незакрытой manipulation candle: запрещён политикой проекта.
