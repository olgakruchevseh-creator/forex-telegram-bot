# Layer 32 — локальная математическая устойчивость

OBSERVE_ONLY слой поверх Layers 21–31. Он не меняет ЛОНГ/ШОРТ, рабочую вероятность, пороги, veto, Telegram или политику закрытой H1.

## Что добавлено

Layer 31 проверяет совместный неблагоприятный стресс математического стека. Layer 32 проверяет другой вопрос: **сохраняется ли математический вывод в небольшой окрестности текущих значений**, если производные оценки слегка двигаются в разные стороны.

Используются 12 фиксированных детерминированных профилей малых смешанных возмущений. Для них считаются:
- baseline_score;
- worst_neighbour_score;
- mean_neighbour_score;
- dispersion;
- доля окрестности, сохранившая не менее заданной части baseline;
- worst retention;
- итоговый local_stability.

Это позволяет отличать действительно устойчивую математическую область от пограничной точки, где небольшая ошибка оценивания резко меняет качество общего вывода.

## Безопасность

- OBSERVE_ONLY = True
- trade_effect = False
- direction_claim = False
- probability_effect = False
- threshold_effect = False
- veto_effect = False
- telegram_effect = False
- закрытая H1 сохранена
- M15/M5 остаются только подтверждением
- результат не является статистической гарантией или торговой вероятностью
