# Pattern 1-2-3 Lifecycle — patch 101

Фактический аудит актуальной базы 2026-10-02 показал: существующий `pattern_123()` уже искал P1/P2/P3 и требовал закрытый пробой P2, но не имел полного lifecycle.

Добавлено без отдельной стратегии:
- ATR-нормированное качество P1→P2 (минимум 0.65 ATR);
- диапазон коррекции P3 и отдельный P3 hold;
- состояние STRUCTURE_ARMED до подтверждения;
- trigger/neckline = Point 2;
- подтверждение только первым закрытием за P2 с ATR-buffer;
- INVALIDATED при нарушении защитной границы P1;
- динамический Breakout Retest Pocket вокруг P2;
- состояния RETEST_POCKET / RETEST_RECLAIM после подтверждения;
- старый пробой не создаёт новый поздний Telegram-сигнал;
- в подтверждённый факт добавлены P1→P2 в ATR, глубина P3 и зона ретеста.

Архитектура сохранена: полноценный Pattern Scanner остаётся W1/D1/H4/H1; M15/M5 не превращены в самостоятельные источники паттерна 1-2-3.

Изменены: `patterns.py`, `config.py`.
Добавлен регрессионный тест: `test_pattern_123_lifecycle_v101.py`.
