# Layer 39 — Coalition Marginal Attribution / Shapley-style Audit

Статус: **OBSERVE_ONLY**. Не меняет ЛОНГ/ШОРТ, вероятности, пороги, veto, Telegram или правила закрытой H1.

## Задача
Layer 38 проверяет устойчивость множества коалиций. Layer 39 отвечает на следующий вопрос: **какой реальный предельный вклад даёт каждая из 9 первичных математических координат во всех возможных составах стека?**

Используется точный Shapley-style перебор subset lattice для существующего консервативного агрегатора. Для каждой координаты измеряется средний marginal contribution при добавлении её к каждой возможной коалиции остальных координат с факториальными весами.

## Что диагностируется
- `marginal_contribution_pct` — предельный вклад каждой координаты;
- `absolute_attribution_share_pct` — доля абсолютного вклада;
- `dominant_attribution_share_pct` — насколько одна координата доминирует;
- `effective_attribution_dimension` — сколько координат фактически несут вклад;
- `negative_marginal_components` — координаты, которые в среднем ухудшают консервативный агрегат.

Состояния: `ATTRIBUTION_DISTRIBUTED`, `ATTRIBUTION_WARNING`, `ATTRIBUTION_CONCENTRATED`.

Мета-слои 30+ не считаются независимыми источниками поддержки. Это детерминированная математическая диагностика, не статистическая гарантия и не торговый сигнал.
