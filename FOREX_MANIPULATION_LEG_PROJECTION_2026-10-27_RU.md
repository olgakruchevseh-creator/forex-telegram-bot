# Forex · Проекция ноги манипуляции · 2026-10-27

## Что добавлено

В Forex добавлен H1-only OBSERVE_ONLY слой проекции подтверждённой CISD-ноги манипуляции.

- геометрия sweep -> origin извлекается из уже существующего CISD без отдельного сигнала;
- уровни: `-1 / -1.5 / -2 / -2.25 / -2.5 / -4 / -4.25 / -4.5`;
- основная зона: `-2 … -2.5`, середина `-2.25`;
- дальняя зона: `-4 … -4.5`, середина `-4.25`;
- подтверждённая H1-геометрия может наблюдаться до 8 последующих закрытых H1;
- для каждого уровня фиксируются касание, первое H1 касания, закрытие через уровень и последующая реакция;
- реакция считается только со следующей закрытой H1 после первого касания, без догадки о внутрисвечном порядке;
- Signal Context получает эту геометрию как телеметрию;
- Decision Journal и Daily Calibration получают OBSERVE_ONLY статистику;
- существующие Navigator/структурные TR1/TR2/TR3 только сопоставляются с зонами; их цены не меняются.

## Causal / anti-repaint

Origin выбирается только из закрытых свечей до sweep. Для жизненного цикла используются только уже закрытые H1-префиксы. M15/M5 не могут создать финальную проекцию — владелец подтверждения для этого слоя только H1 CISD.

## Live-effect

`OBSERVE_ONLY / live_effect=NONE`.

Новая логика не создаёт LONG/SHORT, не меняет пороги CISD/MSS/CHOCH, late-entry guard, invalidation, Telegram publication или существующие цели.
