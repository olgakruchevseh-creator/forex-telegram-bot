FOREX · ЭТАП 7 · ВОЛНЫ ЭЛЛИОТТА (OBSERVE_ONLY)
Дата: 23.11.2026

НАЗНАЧЕНИЕ
Отдельный модуль упрощённого стандартного импульса 1–2–3–4–5
и последующей коррекции A–B–C по уже подтверждённым опорам
канонического ZigZag. Волновая нумерация — ГИПОТЕЗА,
а не подтверждённое торговое направление.

ИЗМЕНЁННЫЕ/НОВЫЕ ФАЙЛЫ (извлечь в корень GitHub репозитория):

2) zigzag_scanner.py                          ЗАМЕНИТЬ
3) briefing.py                                ЗАМЕНИТЬ
4) config.py                                  ЗАМЕНИТЬ
5) test_elliott_waves_observe_stage7_20261123.py НОВЫЙ

ТЕХНИЧЕСКИЙ КОНТРАКТ
- Владелец канонических swing-точек — zigzag_scanner / analysis.zigzag.
  Elliott не пересчитывает ZigZag для D1/H4/H1; W1 используется
  дополнительный отдельный расчёт только для наблюдения.
- Строго закрытые свечи через analysis.closed_candles.
  Текущая открытая H1 и будущие бары не участвуют.
- Каждый W1/D1/H4/H1 считается независимо: нельзя складывать pivot
  от H4 с pivot от H1 и объявлять 1–2–3–4–5.
- M15/M5 остаются младшим контекстом ранее существующих модулей.
  На них нет отдельного «счёта 1–5» и нет волнового разрешения сделки.
- Ветка `elliott_observation` в результате zigzag_scanner.analyze_symbol:
  нет новых сторон, событий, TP, invalidation торговли, блокировок Master.
- «Граница отмены волновой гипотезы» НЕ является торговым стопом.
  Для формирующейся волны 3 пробой экстремума волны 2 отменяет
  именно текущую разметку, а пробой начала волны 1 нарушает
  классическое правило волны 2.
- Строка Эллиотта включена в сессионный брифинг, когда есть
  доступный сценарий; развёрнутые наблюдения прикладываются к
  существующей карточке события ZigZag, без самостоятельной рассылки.
- Все статусы помечены как предварительные / наблюдение.
- Существующий A–B–C слой zigzag_correction_structure самостоятельный;
  не считать его вторым независимым подтверждением волн Эллиотта.

МАТЕМАТИКА
- Непрерывные чередующиеся экстремумы, упорядоченные индексы,
  конечные цены и ненулевые ноги.
- Волна 2 не выходит за начало волны 1.
- Волна 3 проходит за конец волны 1, если уже завершена.
- В обычном импульсе волна 4 не перекрывает территорию волны 1.
- Среди импульсных волн 1/3/5 волна 3 не может быть самой короткой.
  Она НЕ обязана быть самой длинной.
- Укорочение пятой волны допускается, но явно отмечается.
- Для уже закрытых ног 2 и 4 дополнительно проверяются фитили OHLC.
- Фибо: измерительные отношения длин (B/A, C/A, 2/1, 3/1, 4/3, 5/1).
  Фиксированные «магические» числа НЕ используются как строгий допуск.
- Постимпульсная A–B–C проверяется отдельно, только на 1–3 новых
  ZigZag экстремумах; расширенные флэты/треугольники/двойные тройки
  НЕ входят в этот детектор. Диагонали с перекрытием 1 и 4 НЕ входят.

ОГРАНИЧЕНИЯ И НЕРЕШЁННЫЕ ЗАДАЧИ
- Формальная разметка вложенных подразделений 5-3-5-3-5 и полного
  набора разновидностей Эллиотта не выполняется. Это консервативная
  геометрическая гипотеза по ZigZag, а не полный экспертный счёт.
- ZigZag-опоры подтверждаются с задержкой (несколькими свечами);
  в истории номер волны может измениться при новом подтверждённом
  экстремуме. «Подтверждённые pivot» != «бесспорная волна Эллиотта».
- Временной масштаб, начальная опорная точка и альтернативный счёт
  неоднозначны; гипотеза НЕ заменяет Master/Killer.
- Достоверность на реальной истории и качество распознавания
  проверяются отдельной OOS-разметкой, не одними юнит-тестами.

ПРОВЕРКА/ДЕПЛОЙ
1. Загрузить ровно перечисленные файлы в корень GitHub, с заменой
   трёх имеющихся Python-файлов.
2. Дождаться зелёного полного GitHub Actions — локальный набор
   проверяет только доступную часть тестов.
3. Проверить успешный Railway Deploy; новые переменные окружения
   не требуются. Если потребуется полностью выключить слой,
   установить ELLIOTT_WAVES_OBSERVE_ONLY_ENABLED = False в config.py.
4. Смотреть следующие сессионные сообщения «Зигзаг ... Эллиотт»;
   текст появится только при достаточном количестве закрытых pivot.
5. Первые несколько торговых сессий — наблюдать, не утверждать,
   что наблюдательный прогноз имеет исторически доказанное преимущество.
