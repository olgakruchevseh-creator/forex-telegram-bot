# Layer 19 — Evidence Independence / Correlation Audit

Статус: OBSERVE_ONLY.

Слой не считает CHOCH + MSS + Structure тремя независимыми голосами, если они происходят из одной коррелированной структурной семьи. Он показывает концентрацию подтверждений, число независимых семейств и противостоящие семейства.

Не меняет направление, probability, thresholds, veto и Telegram.
