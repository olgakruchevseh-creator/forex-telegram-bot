# Layer 36 — Component Influence / Jackknife Audit

Статус: **OBSERVE_ONLY**.

Layer 36 проверяет, не зависит ли итоговая математическая оценка Layers 21–29 чрезмерно от одного компонента. Для каждого первичного показателя выполняется deterministic leave-one-out проверка: показатель временно исключается только внутри диагностики, после чего измеряется сдвиг агрегированной оценки.

## Что измеряется

- baseline математической оценки;
- leave-one-out score для каждого первичного компонента;
- абсолютное влияние каждого компонента;
- максимальное влияние и dominant component;
- доля доминирующего компонента в общей чувствительности;
- разброс leave-one-out оценок;
- influence health.

Layers 30+ намеренно не считаются независимыми подтверждениями: это производные meta-диагностики.

## Безопасность

Layer 36 не меняет LONG/SHORT, вероятность, торговые пороги, veto, Telegram или правила входа. Политика закрытой H1 сохранена; M15/M5 остаются только подтверждением. Layer не является статистической гарантией.
