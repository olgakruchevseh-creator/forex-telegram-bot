ЧТО ДОБАВЛЕНО:
- Независимое распознавание по последним ЗАКРЫТЫМ свечам W1/D1/H4/H1/M15/M5.
- Для каждого TF используется полный существующий набор детекторов Patterns.
- Сессионный брифинг: компактное представление до двух фигур на каждый TF,
  количество остальных указано как «ещё N»; все шесть TF видны вместе.
- /briefing_full: полное перечисление всех распознанных фигур на этих закрытиях,
  по каждой валютной паре, без ограничения до двух на TF.
- Показаны направление и конфликт фигур; главной (контекстной) считается
  самая старшая обнаруженная HTF-фигура. Это НЕ рейтинг по вероятности.
- M15 и M5 только для OBSERVE_ONLY. Не генерируют дополнительных торговых
  сигналов, не меняют PATTERN_MAIN_TFS и не обходят допуск по закрытой H1.
- Новый ограниченный кеш LTF по подписи закрытых OHLC, не сохраняет свечные массивы.
  Изменение незакрытой свечи не пересчитывает, ревизия закрытой — пересчитывает.
- Лог PATTERNS_MTF_VIEW показывает число фигур на каждом TF, длительность и кеш.
- Существующие сигнальные паттерны, очередь pending, разметка SENT, пороги,
  рисковые проверки, Killer и Swing.dt не изменены.

ВАЖНЫЕ ГРАНИЦЫ ЭТАПА 1:
- Это только фигуры, детектированные на ПОСЛЕДНЕЙ доступной закрытой свече TF.
  Это не полноценное хранилище всех ещё активных паттернов предыдущих свечей.
- Картинка в сессионном брифинге по-прежнему показывает один главный HTF-график;
  остальные фигуры перечислены текстом. Общая визуализация — отдельный этап.
- Число свечей формирования, число закрытых H1 во время формирования,
  длительность ПОСЛЕ подтверждения, откаты и TR1/TR2/TR3 не подсчитываются
  в этом патче. Они потребуют исторического replay по настоящим OHLC,
  новых опорных меток каждого типа и независимой проверки без look-ahead.
- Значение quality/confidence существующих детекторов не считается
  исторически калиброванной вероятностью отработки.

ПРОВЕРКИ:
- 40 целевых и смежных тестов успешно пройдены локально.
- На синтетических данных для 7 пар повторный MTF-обзор использует кеш;
  тестовый замер: первый проход 0.105 с, повторный 0.025 с.
  Это НЕ измерение реальной нагрузки Railway.
- Полный pytest в локальной среде не запущен из-за отсутствия telegram;
  другой расширенный прогон превысил лимит выполнения. После загрузки
  ОБЯЗАТЕЛЬНО проверить полный GitHub Actions до проверки Railway.

УСТАНОВКА:
1. Распаковать архив.
2. Выделить ПЯТЬ Python-файлов из списка выше.
3. Загрузить их в корень того же Forex-репозитория GitHub.
4. Подтвердить замену трёх существующих, два новых добавить.
5. Проверить результат полного GitHub Actions.
6. Убедиться, что Railway получил обновление и worker имеет статус Active.
7. Прислать PATTERNS_MTF_VIEW, PATTERNS_CYCLE и график Memory после нескольких циклов.

НЕ требуется менять переменные Railway и настройки PATTERN_MAIN_TFS.
TXT используется только как инструкция.
